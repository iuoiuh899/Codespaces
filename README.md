# VectorCraft

This repository deploys the VectorCraft web app from the
[v0.24.1 release](https://github.com/storytold/vectorcraft/releases/tag/v0.24.1) to
[GitHub Pages](https://iuoiuh899.github.io/Codespaces/).

The deployment workflow downloads the release archive and publishes its static files on pushes
to `main` or when run manually from the Actions tab.
